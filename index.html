Key Features

Architected in pure Go for efficiency, speed, and clean GTK integration.

Hardware-Accelerated VTE

Full 24-bit truecolor, Unicode rendering, and smooth high-frequency scrolling for Neovim, Tmux, and Htop.

Dynamic Split Panes

Split horizontal or vertical with independent shell processes and navigate boundaries using Alt+[/] or Alt+Arrow keys.

Collapsible Sessions Sidebar

Ctrl+B / F9 toggleable sidebar with active pane counters, quick shell launchers (Fish, Bash), and instant theme picker.

12 Curated Built-in Themes

Kitty Dark, Nord, Dracula, Solarized, Gruvbox, Catppuccin Mocha, Tokyo Night, One Dark, Rosé Pine, Monokai Pro, plus custom TOML themes.

In-Buffer Regex Search

Scrollback search with case sensitivity, regular expressions, previous/next match jumps, and escape shortcuts.

Poppins UI Typography

Modern bold Poppins UI font with 30px height standard on all inputs, buttons, and tab controls.

Configuration Specification

Stored strictly under XDG standard path: ~/.config/termx/config.toml

~/.config/termx/config.toml 
[general]
shell = "/usr/bin/fish"
working_directory = ""
confirm_on_close = true
restore_window_state = true

[appearance]
theme = "kitty-dark"
app_font_family = "Poppins"
font_family = "Monospace"
font_size = 11.0
line_spacing = 1.0
opacity = 1.0
cursor_shape = "block"
cursor_blink = "system"

[terminal]
scrollback_lines = 10000
audible_bell = false
copy_on_select = false

[window]
width = 1200
height = 600
is_maximized = false
sidebar_visible = true
